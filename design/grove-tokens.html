Grove

The token set for Etto's Grove direction, mapped onto the custom properties already in src/index.css. Every text colour here is checked against the surface it sits on for WCAG AA.

Spec — not wired up yet Contrast verified in-page Tailwind v4 · CSS custom properties

01 — Scope

What Grove changes, and what it leaves alone

Grove is a palette-and-material change, not a structural one. It swaps the translucent lenses for solid tonal cards, moves the accent from violet to sage, adds a serif display face for two roles, and defines a matching night palette. The spacing scale, the rem-based type scale, and the component structure are untouched — so the accessibility text-scaling path keeps working as-is.

Changes

  • Accent hue: violet → sage green
  • Material: glass lenses → solid cards; aurora → near-flat ground
  • Body face: Manrope → Figtree
  • New --font-display (Instrument Serif) for the two headline-lg roles only
  • Macro accents re-tuned to clay / sky / rose; every -text variant re-derived for AA
  • Shadows lose the inset specular rim; warm-tinted, softer
  • Full dark palette redefined (not inverted)

Unchanged

  • The --spacing-* scale (4 / 8 grid)
  • The rem type scale and every drawn size
  • Component markup and layout breakpoints
  • Safe-area and chrome-metric tokens
  • Motion tokens and curves
  • Radii, give or take 2px (see Geometry)

04 — Material

The glass rewrite

Grove has no translucency, no backdrop blur, and no specular rim — so the @utility lens classes collapse to solid fills and the glass-* variable set gets much shorter. The structural comments in src/index.css about why the blur lives on a pseudo-element stop applying; the ::before can go.

Was

  • glass: ::before with backdrop-filter, --glass-bg at 0.55 alpha, --glass-rim inset highlights
  • --aurora: four radial gradients + a linear
  • glass-chrome / -sheet / -menu: heavier blur, saturate(180–190%)
  • 9 --glass-* colour values per theme

Now

  • glass: background: var(--color-surface-bright), 1px hairline border, --shadow-card. No pseudo-element.
  • --aurora: a 2-stop vertical gradient, barely there
  • glass-chrome / -sheet: same solid fill, just a stronger shadow
  • --glass-rim: 0 0 transparent — kept as a name so nothing that references it breaks

05 — Type

Two faces, one scale

Figtree replaces Manrope as the UI face — a humanist variable sans with a close x-height, so the rem scale and every drawn size carry over unchanged. Instrument Serif is added as --font-display and used in exactly two places: the headline-lg and headline-lg-mobile roles — the "Today" greeting and the page titles. It has a single weight, so those two roles drop their font-weight and their negative tracking (a serif at display size wants neither).

Figtree ships a single variable file (weights 300–900); Instrument Serif is one static weight. Google Fonts is fine for this spec page and for prototyping, not for the shipped app.

06 — Geometry

Radii, spacing, shadows

Radii — small changes

  • --radius-lens: 28px → 26px
  • --radius-row: 18px → 16px
  • --radius-chrome: 33px → 30px
  • --radius-2xl: unchanged (1.5rem)
  • Pills stay 999px

Spacing — no change

  • The whole --spacing-* scale is untouched
  • Card padding stays --spacing-lg (24px) — Grove mocks at 22px, round to the grid
  • Section gap stays --spacing-lg

Shadows — warm-tinted, no rim

Every shadow loses its inset … rgba(255,255,255,…) highlight pair (that was the glass rim). Light-theme shadows tint toward the ground with rgba(55,66,52,…) instead of blue-black; dark-theme shadows go to near-opaque black. Values in the Material table above.
